## 📱 ¿Qué es Scanza?

**Scanza** es una aplicación de escaneo documental para Android desarrollada por **SSZA - Design**, diseñada para digitalizar documentos directamente desde el teléfono de forma rápida, limpia y práctica.

Permite convertir fotografías de documentos en archivos digitales organizados, aplicar correcciones y mejoras, trabajar con documentos multipágina y generar archivos PDF sin depender de un escáner físico.

---

## ✨ Características

- 📷 Escaneo automático de documentos.
- 📐 Detección y corrección de perspectiva.
- 🪄 Mejora automática de la imagen.
- 📄 Documentos multipágina.
- 📑 Exportación a PDF.
- 🖼️ Exportación a JPG y PNG.
- 🔎 OCR para extracción de texto.
- 🔄 Rotación y organización de páginas.
- 🗂️ Biblioteca local de documentos.
- 📤 Compartir documentos.
- 🖨️ Impresión desde Android.
- 📱 Importación de imágenes desde galería.
- 🔒 Procesamiento local orientado a privacidad.
- 🌙 Interfaz moderna y optimizada para dispositivos móviles.

---

## 🔐 Privacidad

Scanza está diseñada para realizar el procesamiento principal de los documentos **localmente en el dispositivo**.

Tus documentos no necesitan ser enviados a un servidor de SSZA - Design para realizar las funciones principales de escaneo, procesamiento y organización.
