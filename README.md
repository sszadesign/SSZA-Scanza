# 📄 ¿Qué es Scanza?

**Scanza** es una aplicación de escaneo documental para Android desarrollada por **SSZA - Design**, creada para transformar un teléfono móvil en una herramienta práctica de digitalización.

La aplicación permite capturar documentos utilizando la cámara del dispositivo, detectar la hoja, corregir perspectiva, mejorar la imagen, organizar varias páginas y generar archivos digitales listos para almacenar, compartir o imprimir.

Scanza está pensada para situaciones en las que necesitas digitalizar documentos sin depender de un escáner físico.

Su objetivo es mantener un flujo de trabajo sencillo:

> **Abrir → Escanear → Revisar → Guardar → Compartir**

Todo desde el teléfono.

---

# 🎯 Objetivo del proyecto

Scanza nace con una idea concreta:

> **Hacer que digitalizar un documento desde Android sea rápido, limpio y práctico.**

No pretende complicar una tarea sencilla con configuraciones innecesarias.

La aplicación busca ofrecer una experiencia cercana a utilizar un escáner documental convencional, aprovechando la cámara y capacidad de procesamiento del teléfono.

Está orientada a:

- documentos personales;
- documentos administrativos;
- formularios;
- apuntes;
- expedientes;
- recibos;
- constancias;
- páginas impresas;
- documentos multipágina;
- material académico;
- archivos que necesitan ser enviados rápidamente;
- situaciones donde no se dispone de un escáner físico.

---

# ✨ Características principales

## 📷 Escaneo documental

Scanza permite utilizar la cámara del teléfono para digitalizar documentos directamente.

Entre sus funciones se encuentran:

- captura documental mediante cámara;
- detección de la hoja;
- captura automática configurable;
- captura manual;
- corrección de perspectiva;
- procesamiento posterior a la captura;
- mejora de legibilidad;
- manejo de páginas individuales;
- creación de documentos completos.

La aplicación busca identificar la hoja y reducir al mínimo el trabajo manual después de tomar la fotografía.

---

## ⚡ Captura automática

Cuando la opción **Captura automática** está habilitada, Scanza puede asistir durante el proceso de escaneo.

El flujo general es:

```text
Documento
   │
   ▼
Detección
   │
   ▼
Enfoque
   │
   ▼
Captura
   │
   ▼
Corrección
   │
   ▼
Mejora
   │
   ▼
Página escaneada
```

El objetivo es que el usuario tenga que intervenir lo menos posible durante una sesión de digitalización.

---

## 👆 Captura manual

Scanza también mantiene un modo manual para situaciones donde el usuario necesita controlar directamente el momento de la fotografía.

En este modo:

- se muestra una guía visual;
- el usuario posiciona el documento;
- realiza la captura manualmente;
- Scanza procesa la página posteriormente.

Esto resulta útil cuando:

- hay poca iluminación;
- el documento tiene bordes difíciles de distinguir;
- el fondo tiene muchos elementos;
- el usuario necesita controlar exactamente el momento de captura.

---

# 📚 Documentos multipágina

Scanza permite crear documentos formados por múltiples páginas dentro de una misma sesión.

No es necesario guardar cada página como un documento separado.

Puedes continuar agregando páginas hasta completar el documento.

Durante la revisión es posible:

- visualizar las páginas;
- comprobar el orden;
- rotarlas;
- reorganizarlas;
- eliminar páginas incorrectas;
- revisar el resultado antes de guardar.

Finalmente, todas las páginas pueden convertirse en un único archivo PDF.

Esto permite utilizar Scanza para documentos extensos como:

- expedientes;
- contratos;
- informes;
- formularios;
- trabajos académicos;
- documentación administrativa;
- documentos de varias decenas de páginas.

---

# 📐 Corrección de perspectiva

Las fotografías tomadas con un teléfono rara vez quedan completamente perpendiculares al documento.

Scanza incorpora procesamiento para corregir la perspectiva de la página detectada.

El objetivo es transformar una captura inclinada:

```text
    /-----------/
   / Documento /
  /-----------/
```

en una página digital visualmente recta:

```text
┌───────────────┐
│               │
│   Documento   │
│               │
└───────────────┘
```

Esto ayuda a obtener documentos más limpios y apropiados para:

- lectura;
- impresión;
- almacenamiento;
- generación de PDF;
- OCR.

---

# 🪄 Mejora del documento

Después de capturar una página, Scanza puede aplicar procesamiento de imagen para mejorar el resultado.

La aplicación dispone de diferentes opciones visuales según el tipo de documento.

Esto puede ayudar cuando existen:

- sombras;
- diferencias de iluminación;
- fondos poco uniformes;
- fotografías con bajo contraste;
- documentos que necesitan mayor claridad.

El objetivo no es modificar el contenido del documento, sino mejorar su presentación digital.

---

# 🔎 OCR — Reconocimiento de texto

Scanza incorpora **OCR (Optical Character Recognition)** para extraer texto de documentos escaneados.

Esto permite que una página no sea únicamente una fotografía.

El texto reconocido puede utilizarse para:

- consultar información;
- copiar contenido;
- recuperar texto de una página;
- facilitar búsquedas;
- reutilizar información contenida en documentos impresos.

El OCR se procesa localmente en el dispositivo utilizando las capacidades compatibles disponibles en Android.

---

# 🖼️ Importación desde galería

No todos los documentos necesitan fotografiarse directamente desde Scanza.

La aplicación también permite importar imágenes existentes desde la galería del teléfono.

Esto resulta útil cuando tienes:

- fotografías tomadas anteriormente;
- páginas recibidas por mensajería;
- imágenes descargadas;
- documentos fotografiados con otra aplicación;
- páginas almacenadas previamente en el dispositivo.

Una imagen importada puede incorporarse al flujo documental de Scanza.

---

# 🗂️ Biblioteca de documentos

Scanza incluye una biblioteca local para consultar documentos previamente guardados.

Esto permite mantener los archivos organizados dentro de la aplicación y acceder a ellos posteriormente sin necesidad de volver a digitalizarlos.

Desde la biblioteca puedes trabajar con tus documentos almacenados y recuperar rápidamente archivos anteriores.

---

# 🔍 Búsqueda

La biblioteca de Scanza incorpora funciones de búsqueda para facilitar la localización de documentos.

Esto resulta especialmente útil cuando la cantidad de archivos guardados comienza a crecer.

El objetivo es evitar tener que revisar manualmente cada documento para encontrar uno específico.

---

# 🔄 Gestión de páginas

Antes de guardar un documento, Scanza permite revisar las páginas de la sesión.

Entre las acciones disponibles se encuentran:

- rotar páginas;
- cambiar el orden;
- eliminar páginas incorrectas;
- revisar cada captura;
- aplicar mejoras;
- continuar agregando páginas.

Esto permite corregir una sesión sin tener que comenzar el documento completo desde cero.

---

# 📑 Exportación PDF

Uno de los principales objetivos de Scanza es generar documentos PDF desde páginas escaneadas.

Las páginas capturadas pueden convertirse en un solo archivo:

```text
Página 1
Página 2
Página 3
Página 4
   │
   ▼
┌─────────────────┐
│ Documento.pdf   │
└─────────────────┘
```

Esto facilita:

- enviar documentación;
- guardar expedientes;
- compartir informes;
- imprimir documentos;
- archivar páginas digitalizadas.

---

# 🖼️ Exportación de imágenes

Además de PDF, Scanza permite trabajar con formatos de imagen comunes.

| Formato | Uso |
|---|---|
| **PDF** | Documentos completos y multipágina |
| **JPG** | Compatibilidad general y páginas individuales |
| **PNG** | Exportación de imagen con alta compatibilidad |

Esto permite elegir el formato más adecuado dependiendo del uso del documento.

---

# 📦 Compresión

Los documentos digitales pueden ocupar una cantidad considerable de almacenamiento, especialmente cuando contienen muchas páginas.

Scanza dispone de opciones de calidad y compresión para equilibrar:

- calidad visual;
- tamaño del archivo;
- facilidad para compartir;
- almacenamiento disponible.

Esto resulta especialmente útil en documentos multipágina.

---

# 📤 Compartir

Los archivos generados pueden compartirse utilizando las aplicaciones compatibles instaladas en Android.

Por ejemplo:

- correo electrónico;
- aplicaciones de mensajería;
- almacenamiento en la nube;
- gestores de archivos;
- otras aplicaciones compatibles con PDF o imágenes.

Scanza utiliza el sistema de compartir disponible en Android.

---

# 🖨️ Impresión

Los documentos generados también pueden enviarse al sistema de impresión de Android.

La disponibilidad final depende de:

- dispositivo;
- impresora;
- servicios de impresión configurados;
- aplicaciones instaladas.

Esto permite pasar directamente de un documento escaneado a una impresión cuando el entorno lo permite.

---

# 🔒 Privacidad

La privacidad documental es una consideración importante dentro de Scanza.

Las funciones principales de procesamiento se realizan **localmente en el dispositivo**.

Scanza no necesita enviar los documentos a servidores de **SSZA - Design** para realizar las principales funciones de:

- escaneo;
- corrección;
- procesamiento;
- organización;
- generación de PDF;
- OCR local;
- almacenamiento de documentos.

Los documentos permanecen bajo el control del usuario en su dispositivo.

---

# 📱 Procesamiento local

Scanza está diseñada para aprovechar el procesamiento disponible en Android.

Esto significa que muchas funciones pueden trabajar directamente desde el teléfono sin depender de una conexión permanente con un servidor externo.

Entre las ventajas se encuentran:

- mayor privacidad;
- menor dependencia de Internet;
- procesamiento inmediato;
- control local de los documentos.
