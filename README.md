## Acerca de Scanza

**Scanza** es una aplicación de escaneo documental para Android desarrollada por **SSZA - Design**.

Está diseñada para convertir un teléfono en una herramienta práctica de digitalización, permitiendo capturar, mejorar, organizar y exportar documentos sin depender de un escáner físico para tareas cotidianas.

Scanza combina captura documental, procesamiento de imagen, documentos multipágina, OCR y generación de PDF dentro de una interfaz móvil limpia y directa.

---

## Escaneo automático

Scanza está diseñada para reducir al mínimo la intervención del usuario durante la captura.

El flujo de escaneo puede realizar:

**Detección → Captura → Corrección → Mejora → Documento**

Cuando la captura automática está habilitada, Scanza intenta identificar la hoja y procesarla directamente.

También dispone de captura manual cuando el usuario necesita mayor control sobre el momento de la fotografía.

---

## Documentos multipágina

Scanza permite crear documentos formados por múltiples páginas dentro de una misma sesión.

Las páginas pueden:

- visualizarse antes de guardar;
- rotarse;
- reorganizarse;
- eliminarse;
- procesarse individualmente;
- exportarse finalmente como un solo PDF.

Esto permite trabajar con documentos extensos directamente desde el teléfono.

---

## OCR

Scanza incorpora reconocimiento óptico de caracteres para extraer texto de documentos escaneados.

El OCR está orientado a ejecutarse directamente en el dispositivo y permite consultar o reutilizar el contenido textual de un documento cuando sea necesario.

---

## Exportación

Los documentos pueden utilizarse en diferentes formatos según la necesidad:

| Formato | Uso |
|---|---|
| **PDF** | Documentos multipágina, archivo e impresión |
| **JPG** | Compatibilidad y uso general |
| **PNG** | Imagen individual con alta compatibilidad |

Scanza también permite compartir documentos utilizando las aplicaciones disponibles en Android.

---

## Privacidad

La privacidad forma parte del diseño de Scanza.

El procesamiento principal de documentos se realiza **localmente en el dispositivo**.

Scanza no requiere que los documentos sean enviados a servidores de **SSZA - Design** para realizar las funciones principales de:

- escaneo;
- procesamiento de imagen;
- organización;
- generación de PDF;
- OCR local.

Los archivos permanecen bajo el control del usuario en su dispositivo.
