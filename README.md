## Acerca de Scanza

**Scanza** es una aplicación de escaneo documental para Android desarrollada por **SSZA - Design**, creada para convertir un teléfono móvil en una herramienta práctica de digitalización de documentos.

La aplicación permite capturar documentos utilizando la cámara del dispositivo, procesar las páginas, aplicar mejoras, organizar documentos multipágina y generar archivos digitales listos para almacenar, compartir o imprimir.

Scanza está orientada a ofrecer una experiencia sencilla, limpia y funcional, reduciendo la necesidad de utilizar un escáner físico para tareas documentales cotidianas.

---

## Características principales

### Escaneo documental

- Captura de documentos mediante la cámara.
- Captura automática configurable.
- Modo de captura manual.
- Detección de la hoja.
- Corrección de perspectiva.
- Procesamiento automático después de la captura.
- Mejora visual del documento.
- Compatibilidad con documentos verticales y horizontales.

### Documentos multipágina

Scanza permite crear documentos de varias páginas dentro de una misma sesión.

Es posible:

- agregar múltiples páginas;
- visualizar las páginas capturadas;
- rotarlas;
- reorganizarlas;
- eliminar páginas individuales;
- aplicar mejoras;
- generar un único documento final.

Esto permite trabajar con expedientes, formularios, apuntes, documentos administrativos y otros archivos de varias páginas directamente desde el teléfono.

### Procesamiento de imagen

Scanza incorpora herramientas para mejorar la legibilidad de los documentos capturados.

Dependiendo del documento y de las condiciones de captura, pueden utilizarse diferentes modos de procesamiento para obtener un resultado más limpio y adecuado para lectura, almacenamiento o impresión.

### OCR

La aplicación incorpora **reconocimiento óptico de caracteres (OCR)** para extraer texto de documentos digitalizados.

El OCR permite aprovechar el contenido textual de una página escaneada sin depender exclusivamente de la imagen del documento.

El procesamiento OCR se realiza en el dispositivo cuando esta función se encuentra habilitada.

### Importación desde galería

Además de utilizar la cámara, Scanza permite trabajar con imágenes existentes en el dispositivo.

Esto resulta útil para:

- fotografías de documentos tomadas anteriormente;
- imágenes recibidas por otros medios;
- documentos almacenados en la galería;
- páginas que necesitan incorporarse a un nuevo archivo.

### Biblioteca de documentos

Los documentos guardados pueden consultarse desde la biblioteca local de Scanza.

La aplicación permite organizar y recuperar documentos previamente digitalizados sin necesidad de realizar nuevamente el escaneo.

### Exportación

Scanza permite trabajar con diferentes formatos según la necesidad del usuario.

| Formato | Uso recomendado |
|---|---|
| **PDF** | Documentos completos y multipágina |
| **JPG** | Imágenes individuales y compatibilidad general |
| **PNG** | Exportación de páginas en formato de imagen |

Los documentos también pueden compartirse utilizando las aplicaciones compatibles instaladas en Android.

### Impresión

Los documentos generados pueden enviarse al sistema de impresión disponible en Android cuando el dispositivo y las aplicaciones instaladas lo permitan.
